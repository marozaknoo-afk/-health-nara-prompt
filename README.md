# Health Nara Prompt Studio

เว็บสร้าง Master Prompt สำหรับงานสุขภาพและราชการไทย พร้อมคลังพาเลตต์ 190 ชุด และหลักเกณฑ์การสร้างภาพ [01]–[08]

## ความสามารถหลัก

- ค้นหาและเลือกพาเลตต์จาก 18 หมวดหมู่
- กำหนดประเภทเนื้อหา อัตราส่วนภาพ พื้นหลัง และสไตล์งาน
- พรีวิวสดและสร้าง Master Prompt โดยอัตโนมัติ
- อ่านข้อมูลจาก TXT, Markdown, Word และ Excel ภายในเบราว์เซอร์
- เลือก **เครื่องมือปลายทาง** (ทั่วไป / ChatGPT·Gemini / Midjourney / Stable Diffusion) และความยาว เต็ม/กระชับ — ระบบจัดรูปแบบให้ตรงกับเครื่องมือ รวมถึง `--ar` `--no` และช่อง Negative prompt แยก
- **ตัวอักษรไทยในภาพ**: เลือกแบบอักษรราชการ (สารบรรณ / พิธีการ / ข้อมูล) และโหมดข้อความ — "ให้ AI เขียน" (ระบุข้อความทีละบรรทัด + กฎวรรณยุกต์/สระ + รายการตรวจ) หรือ "เว้นพื้นที่ว่างแล้ววางข้อความเอง" ซึ่งเป็นวิธีเดียวที่รับประกันตัวอักษรถูกต้อง 100%
- **ตรวจก่อนคัดลอก**: เตือนเมื่อเนื้อหาว่าง ไม่มีตัวเลขในงานตัวชี้วัด ยาวเกินไป อัตราส่วนไม่เหมาะ หรือพบเลขบัตรประชาชน/เบอร์โทร (PDPA)
- Preset 10 แบบ และ **ชุดของฉัน** (บันทึกเฉพาะการตั้งค่า ไม่รวมเนื้อหา)
- **ลิงก์แชร์** ที่เก็บเฉพาะการตั้งค่า และนำเข้า JSON ที่เคยส่งออก
- คัดลอก Prompt และส่งออก JSON/CSS
- รองรับมือถือ เดสก์ท็อป Light Mode และ Dark Mode

## ความปลอดภัยของข้อมูล

- เนื้อหาที่ผู้ใช้กรอกไม่ถูกเก็บในเบราว์เซอร์ ไม่อยู่ในลิงก์แชร์ และไม่อยู่ใน "ชุดของฉัน"
- ค่าที่มาจากลิงก์ ไฟล์นำเข้า หรือที่เก็บในเครื่อง ต้องตรงกับตัวเลือกที่หน้าเว็บมีเท่านั้น จึงฝังคำสั่งแปลกปลอมลงใน Prompt ไม่ได้
- ไฟล์ที่แนบถูกอ่านในเบราว์เซอร์เท่านั้น ไลบรารี SheetJS และ mammoth ตรึงเวอร์ชันและตรวจ SRI

## เปิดใช้งานในเครื่อง

เปิด `index.html` ด้วยเบราว์เซอร์ได้โดยตรง หรือรัน static server:

```powershell
npx --yes http-server . -p 4173 -c-1
```

จากนั้นเปิด `http://localhost:4173`

## ทดสอบ

```powershell
node --test
```

ชุดทดสอบรันโค้ดจริงของ `buildPrompt()` ในโหมดจำลอง DOM ไม่ต้องติดตั้งแพ็กเกจใด ๆ (ต้องใช้ Node 18 ขึ้นไป)
